# 머니메모

고정비 합계와 투자 기록을 폰에서 간단히 보는 웹앱(PWA)입니다.

- 고정비: 항목 추가/수정/삭제, 월 합계, 연간 환산, 카테고리(자동 분류 또는 직접 지정)별 비중
- 투자: 투자 묶음(돈의 출처별)마다 보유 종목, 비중, 실현 손익, 남은 현금, 거래 기록
- 설정: 백업 파일 저장/불러오기, 카테고리와 투자 묶음 관리

데이터는 서버로 보내지 않고 각 기기의 브라우저 저장소(localStorage)에만 저장됩니다.

## 설치
GitHub Pages 주소를 폰에서 연 뒤
- 아이폰: 사파리 공유 버튼 → 홈 화면에 추가
- 안드로이드: 크롬 메뉴 → 홈 화면에 추가 / 앱 설치

## 수정할 때
`sw.js`의 `CACHE` 버전과 `app.js`의 `APP_VERSION`을 함께 올려야 폰에 새 버전이 들어갑니다.
